- 저장소: `silverylaker-cmyk/tinnitus-cbt`, 브랜치 `claude/progressive-muscle-relaxation-script-u89u6i` (main에는 아직 병합하지 않음)

## 1. 무엇을 기준으로 바꿨나

기준 자료는 보건복지부 영상 「근육이완 운동」입니다. 장면을 떠올리며 부위별로 긴장했다가 푸는 방식입니다(진흙탕, 레몬, 정수리의 실, 파리).

| 항목 | 개편 전 앱 | 복지부 영상 | 개편 후 앱 |
|---|---|---|---|
| 방식 | 고전 PMR, 동작 지시만 | 장면 떠올리기 | 장면 떠올리기 + 앱의 안전·호흡 안내 |
| 부위 | 14개 | 약 9개 + 고개 돌리기 | 10단계 |
| 순서 | 손·팔 → 얼굴 → 몸통 → 다리 (위→아래) | 발 → 배 → 팔 → 어깨 → 목 → 얼굴 (아래→위) | 영상과 같게 아래→위 |
| 반복 | 부위마다 1회 | 몸 2회, 얼굴 1회 | 영상과 같게 |
| 시간 | 긴장 7초 / 이완 12초, 15~20분 | 나레이션 속도 따름 | 긴장 7초 / 이완 15초, 약 7분 |
| 이명 연결 | 있음 | 없음 | 유지 ("이명이 들려도 그대로 두세요") |
| 안전 안내 | 70~80% 힘 | 없음 ("최대한", "아주 세게") | 70~80% 힘, 다친 부위 건너뛰기, 목·턱 부드럽게, 이 악물지 않기 |

**앱에서 코끼리 장면은 뺐습니다.** 배 단계는 "배에 힘을 줘서 매우 단단하게 만들고 그대로 유지합니다"로만 안내합니다.

### 2-1. 원고 (`content/week5/training.json`) — 현재 전문

화면 1 「근육이완 — 준비와 기본 동작」, 화면 2 「근육이완 — 발에서 이마까지」 (`-----` 아래가 화면 2)

```
긴장하면 나도 모르게 몸에 힘이 들어가고, 어깨 결림이나 근육통으로 이어집니다. 이 근육 감각은 다시 마음의 긴장을 키웁니다. 반대로 마음이 안정되면 근육이 풀리고, 편안한 몸의 감각은 다시 마음의 안정으로 이어집니다. 근육이완은 이 연결을 거꾸로 이용해, 몸부터 풀어서 마음을 가라앉히는 연습입니다.

준비:

- 조용하고 방해받지 않는 곳에서, 의자에 앉거나 침대에 눕습니다
- 조이는 옷, 안경, 시계는 풀어둡니다
- 10분 정도 확보합니다 (자기 전에 하면 수면에도 도움이 됩니다)

기본 동작 (모든 부위 공통):

1. 장면을 떠올리며 해당 근육을 7초간 긴장시킵니다 (아프지 않을 정도로, 70~80% 힘)
2. 천천히 숨을 내쉬며 힘을 풀고, 15초간 풀린 느낌을 음미합니다
3. 긴장할 때와 풀렸을 때의 차이에 주의를 기울입니다

호흡 요령: 긴장시킬 때 숨을 들이쉬고, 풀 때 길게 내쉽니다. '후—' 하고 내쉬는 숨과 함께 힘이 빠져나간다고 상상하면 좋습니다.

주의: 다치거나 아픈 부위는 건너뛰거나 힘을 아주 약하게 줍니다. 목과 턱은 특히 부드럽게 — 이명이 있는 분 중에는 목·턱관절이 예민한 분이 많습니다. 쥐가 날 것 같으면 바로 힘을 푸세요.
-----
진흙탕, 레몬, 정수리의 실, 파리처럼 장면을 떠올리면 어디에 어떻게 힘을 줄지 쉽게 따라 할 수 있습니다. 아래에서 위로, 발부터 이마까지 진행합니다.

1. 발·종아리 (2회) — 넓은 진흙탕을 맨발로 딛고 있다고 상상합니다. 발바닥으로 진흙을 힘껏 아래로 누르고, 발가락을 펴서 진흙이 발가락 사이로 올라오는 느낌을 느껴봅니다 → 풀기: 진흙탕에서 나와 발을 편하게 둡니다. 긴장이 풀린 나른하고 저릿한 느낌을 느껴봅니다
2. 배 (2회) — 배에 힘을 줘서 매우 단단하게 만들고 그대로 유지합니다 → 풀기: 천천히 내쉬며 배의 힘을 풉니다. 단단할 때와 편안할 때의 차이를 느껴봅니다
3. 왼손·팔 (2회) — 왼손에 레몬 하나를 쥐고 있다고 상상합니다. 손목을 몸 쪽으로 당기며 주먹을 쥐고, 과즙이 남지 않도록 꽉 짭니다 → 풀기: 레몬을 내려놓듯 천천히 손을 폅니다. 손과 팔이 얼마나 편해졌는지 느껴봅니다
4. 오른손·팔 (2회) — 이번에는 오른손에 레몬을 쥐고, 손목을 몸 쪽으로 당기며 주먹을 쥐어 꽉 짭니다 → 풀기: 레몬을 내려놓듯 천천히 손을 폅니다. 손과 팔이 얼마나 편해졌는지 느껴봅니다
5. 어깨·팔뚝 (2회) — 양 어깨를 귀 가까이 최대한 들어 올리고, 팔뚝을 몸통에 꼭 붙인 채 힘을 줍니다 → 풀기: 깊이 내쉬며 어깨를 내려놓습니다. 어깨와 팔뚝의 편안함을 느껴봅니다
6. 고개 돌리기 (힘 주지 않고 20초) — 고개를 좌우로, 쉽고 편한 만큼만 천천히 부드럽게 돌립니다. 어느 쪽이 더 부드럽게 돌아가는지 양쪽의 차이를 느껴봅니다
7. 목 뒤 (2회) — 정수리에 달린 실을 누군가 위로 당긴다고 상상합니다. 턱을 부드럽게 아래로 당기고 목 뒤를 늘립니다. 어깨는 따라 올라가지 않게 합니다 → 풀기: 천천히 내쉬며 힘을 풉니다. 풀린 목의 편안함을 느껴봅니다
8. 오른쪽 볼·입꼬리 — 귀찮은 파리가 오른쪽 입꼬리에 앉았습니다. 입꼬리를 오른쪽 위로 최대한 끌어올리고 볼과 턱의 긴장을 느낍니다 (이는 악물지 않습니다) → 풀기: 입꼬리를 내려놓고 볼과 턱의 편안함을 느껴봅니다
9. 왼쪽 볼·입꼬리 — 이번에는 파리가 왼쪽 입꼬리에 앉았습니다. 입꼬리를 왼쪽 위로 최대한 끌어올립니다 → 풀기: 입꼬리를 내려놓고 볼과 턱의 편안함을 느껴봅니다
10. 이마 — 파리가 이마에 앉았습니다. 주름 사이에 파리를 가둘 만큼 이마에 주름을 많이 만들고 단단하게 유지합니다 → 풀기: 내쉬며 이마를 펴고, 편안해진 이마의 감각을 느껴봅니다

아래 '안내에 따라 해보기'에서 '시작'을 누르면 부위마다 긴장 7초 → 이완 15초를 세어 주고, 바뀔 때마다 작은 소리로 알려 줍니다. 눈을 감고 소리만 따라가도 됩니다. 마지막에는 1분간 천천히 호흡하며 마무리합니다 (전체 약 7분).

일어날 때는 서두르지 말고 천천히 움직이세요. 익숙해지면 일상에서 긴장을 느낄 때 한 부위만 골라 해도 좋습니다.

연습 중 이명이 들려도 그대로 두세요. 몸이 풀리면 이명에 대한 반응도 함께 부드러워지는 것을 경험하게 됩니다.
```

원고 줄 형식은 타이머가 읽는 규칙입니다(아래 2-2). `N. 부위 (2회) — 조이는 안내 → 풀기: 푸는 안내`

### 2-2. 안내 타이머 (`illustrations.js` 의 `mountPMR`, `parsePMRParts`)

- 원고 줄을 읽어 부위별로 이름, 긴장 안내, 풀기 안내, 반복 횟수, 움직이기 단계를 만듭니다.
  - `(2회)` → 2번 반복, 표시가 없으면 1회
  - `(힘 주지 않고 20초)` → 긴장·이완 없이 20초 동안 천천히 움직이는 단계 (고개 돌리기)
  - ` → 풀기: ` 뒤의 문장 → 이완 구간에 보여 줌
- 진행 순서: 준비 5초 → [부위×회차: 긴장 7초 → 이완 15초] → 마무리 호흡 60초. 전체 약 7분
- 화면: "3 / 10 · 1/2회", 부위 이름, 지금 안내 문장, "긴장 5"처럼 남은 초, 단계 진행 막대, 전체 진행 막대
- 긴장 구간은 카드 배경이 주황빛(`--accent-soft`)이 됩니다
- **소리 알림**(기본 켜짐, 끌 수 있음): 긴장 시작은 높은 음(660Hz), 이완·움직이기·마무리는 낮은 음(440Hz), 끝은 523Hz. Web Audio로 만든 짧은 사인파라 눈을 감고 따라 할 수 있음
- 버튼: 시작, **잠깐 멈춤 / 이어서 하기**, 다음 부위(남은 회차를 건너뜀), 그만하기
- 끝까지 마치면 오늘 일기에 '근육이완'이 자동 체크됨 (기존 기능 유지)
