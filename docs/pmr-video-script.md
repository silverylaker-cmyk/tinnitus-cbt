# 근육이완 운동 — 복지부 영상 대본 (편집본)

원본: Google Drive 「근육이완 운동 — 동영상 대본」. 영상 편집 때 아래 기준으로 자릅니다.

## 영상에서 잘라낼 대사

| 구간 | 대사 | 처리 |
|---|---|---|
| 배 | 풀밭에 누워 귀여운 아기 코끼리를 보고 있다고 상상해봅니다. | 삭제 |
| 배 | 아기 코끼리가 주위를 살피지 않고 걸어오다가 당신의 배를 밟고 지나가려고 합니다. | 삭제 |
| 배 | 아기 코끼리가 다른 쪽으로 갑니다. | 삭제 |

확인 필요: 위 세 줄을 빼면 "달아날 시간이 없어서 아기 코끼리가 그냥 배를 밟고 가도록 둡니다."와
"다시 아기 코끼리가 오고 있습니다."에만 코끼리가 남아 맥락 없이 등장합니다. 이 두 줄도 뺄지 결정.

## 영상에 얹을 보완 (화면 자막·그래픽)

- 부위 제목 자막: 발·종아리 → 배 → 왼손·팔 → 오른손·팔 → 어깨·팔뚝 → 고개 돌리기 → 목 뒤 → 오른쪽 입꼬리 → 왼쪽 입꼬리 → 이마 (앱 5주차와 같은 10단계)
- 긴장 구간: "긴장" 표시 + 남은 초 카운트다운, 이완 구간: "이완" 표시 + 카운트다운 (앱 타이머와 같은 색)
- 반복 표시: "1/2회", "2/2회"
- 첫 부분 안전 자막: "아프지 않을 만큼(70~80% 힘)만 · 다친 부위는 건너뛰세요 · 목·턱은 부드럽게"
- 턱·입꼬리 구간: "이는 악물지 않습니다"
- 끝부분: 마무리 호흡 안내 + "연습 중 이명이 들려도 그대로 두세요"
- 실제 영상 확인 결과: 도입부 반복은 없고(호흡 안내로 시작), 오른손 레몬도 2회 모두 있음 — 대본 문서의 두 문제는 영상에는 해당 없음
