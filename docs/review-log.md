# 검토-수정 기록 (5회 루프)

기준: (1) 내용이 자연스러운지 (2) 환자가 결과를 입력·수정·다시 보기 쉬운지 (3) 고령 환자가 사용하기 적합한지

각 회차마다 새 검토자(다른 관점)가 앱 전체를 읽고 지적한 사항과, 그에 따라 수정한 내용을 적습니다.
원고(임상 텍스트) 수정은 표현·오탈자·화면 명칭 일치 수준으로 제한했습니다.

## 1회차 — 고령 환자(72세, 스마트폰 서툰) 관점

**지적 → 수정**
- 글자 크기 설정이 본문에 적용되지 않음(px 고정) → body를 rem으로, 상단 바에 "가A" 글자 크기 버튼 추가
- 호흡/이완 실습 후 홈에 "오늘 기록을 마쳤습니다 · null" 표시 → 실제 저장된 일기만 인정, 전달 데이터에서도 제외
- 마지막 화면 버튼("홈으로", "연습하러 가기" 등)이 항상 목록으로 감 → 홈/같은 주차의 다음 모듈로 실제 이동
- 누적형 워크시트: 저장하면 칸이 비워져 "지워졌다"고 느낌, 나갈 길 없음 → 저장 직후 "방금 저장되었습니다" 표시와 스크롤, "다 적었어요 · 다음으로" 버튼
- 일기 슬라이더 기본값 5가 그대로 저장됨 → 0~10 숫자 버튼, 미선택 시 저장 막음. 문구를 쉬운 말로
- 저장본과 임시 글이 섞여 "고쳤는데 안 바뀜" → 저장하지 않은 수정이 있으면 알림과 '버리기', 단일형에 "저장됨 · 시각" 표시
- 병원 태블릿 사본(JSON)으로 폰 복구 불가 → 사본 형식도 가져오기 지원
- 토스트가 하단 버튼을 가림 → 상단 표시. 회색 보조 글자 대비 부족 → 더 진하게, 크기 상향
- THI 등급 "고도/심도" 표현 → "심한 편/매우 심한 편" 등 쉬운 말, "참고용" 안내. 미응답 문항 배경 강조, 진행 수 고정 표시
- 밀린 주차가 홈에서 안 보임 → 열린 주차 중 가장 앞선 미완료 항목 안내. 잠긴 주차에 열리는 날짜 표시
- 시작 전 '프로그램' 탭이 말없이 튕김 → 안내. 시작 카드를 맨 위로, 홈 화면 추가 안내
- QR 화면: 누가 무엇을 비추는지 모호 → "선생님께 보여 주세요"로, 직원용 버튼 접기, 화면 꺼짐 방지(Wake Lock)
- 소리: 영상 ID가 하나도 없으면 "준비 중" 안내만. 큰 "멈추기" 버튼 추가
- 원고: "Week N 정리"→"N주차 정리", 탭 이름을 원고와 일치("일기", "소리"), '사고기록지 연습'→'사고 기록지 작성', 'VAS'→쉬운 말, 워크시트 라벨 이중 번호 제거, 이완 타이머 시간 안내
- 악순환 고리 설명 글자가 흐려지는 애니메이션 → 강조만 하고 흐려지지 않게

## 2회차 — 임상 원고 편집자 관점 (내용 자연스러움, 용어·화면 명칭 일치)

**원고가 앱 동작과 어긋나던 곳**
- 1주차 숙제: 일기 항목이 2개로 적혀 있으나 앱은 3개(수면 영향 포함) → 원고를 앱과 일치, 소리 치료 안내 추가
- 6주차 숙제/워크시트: "시도할 때마다 적용 기록을 채워" 라고 하지만 단일형(덮어쓰기) → "한 줄씩 덧붙여 적고 다시 저장" 으로
- 호흡·이완 마침 문구가 "체크해 두세요" 라고 하나 앱이 자동 체크 → "자동으로 표시되었습니다. 일기도 저장해 주세요"
- 5주차: '안내에 따라 해보기'는 제목이고 버튼은 '시작' → 문장 수정. 1주차 워크시트 "이후 다시 참고하게 됩니다"(실제로 참고 안 함) 삭제
- 1주차 설문 버튼 "완료"→"제출하기", 제출하면 결과가 바로 보인다고 안내
- 제목·소제목이 같아 두 번 보이던 화면 → 같으면 한 번만 표시. 숙제 모듈 라벨 "이번 주 할 일"→"숙제"
- 목록과 소제목이 섞인 문단이 깨져 보이던 문제 → 본문 렌더러 개선 (모든 모듈 검사 통과)

**용어 통일과 자연스러운 표현**
- '사고 기록지 작성'→'사고기록지 연습', '워크시트: 나의 악순환 그리기'→'나의 악순환 그리기'
- 사운드 테라피/사운드 요법 → '소리 치료', 트리거 상황 → '거슬리는 순간', 페어링 → '짝짓기', 입면 → '잠들기', 자율신경 각성 → '몸의 경계 태세', 팔로우업 → '추적 진료', Week N → N주차
- '당신' 번역투 → '여러분/나', 1주차 첫 화면의 딱딱한 문장 정리, 이중 대시 삽입구 정리, "금지"→"피하기", "인지재구성" 예고를 실제 2주차 내용으로
- UI 문구: 기술적인 오류 메시지 → 환자가 할 일을 알려 주는 말로, 기록 표 머리글 '신경'→'신경 쓰임', 'PMR'→'근육이완'

## 3회차 — 입력·수정·다시보기 흐름 감사 (인터랙션 디자이너 관점)

**버그**
- 누적형 워크시트: 고치는 중에 그 기록을 삭제하면 상태가 꼬여 "저장했습니다"만 뜨고 아무것도 저장 안 됨 → 삭제 시 고치기 모드 해제
- 고친 내용 저장 후 쓰다 만 새 글(임시 보관)이 되살아나지 않음 → 고치기 종료 시 임시 글 복원. 고치던 중 나가도 이어서 고칠 수 있게 별도 보관
- 시작 전/잠긴 주차 접근 시 뒤로가기 함정(history push) → replace로
- 4주차 행동실험: "실행 후 4~5번을 채워 한 번 더 저장"이 누적형에선 실험이 두 기록으로 쪼개짐 → "저장된 기록의 '수정'을 눌러 채우기"로 원고·숙제 수정
- 실습(호흡/이완)만 하고 일기를 안 쓴 날이 기록·전달에서 사라짐 → 실습만 한 날도 표(점수 '–')와 전달 데이터에 포함, 실습 후 "오늘 일기 쓰러 가기" 버튼
- 소리 사용 기록이 30일이라면서 8건만 보임 → 기록 화면은 60건 + "외 N건"
- 태블릿: 폰 기록이 지워진 환자가 다시 보내면 병원의 더 온전한 사본을 덮어씀 → 일기 일수가 줄면 확인 후 교체

**흐름**
- 이미 마친 워크시트(위기 카드, 축약 이완 설계)를 고칠 때마다 다음 모듈로 튕김 → 버튼 "저장", 저장 후 머무르거나 온 곳으로 돌아감
- THI 재제출 시 25문항을 다시 답해야 함 → 이전 답을 채워 두고 고칠 문항만 바꾸게
- 지난 일기를 기록 표에서 고친 뒤 홈으로 감 → 온 곳으로 돌아감, '취소' 버튼
- 기록 표에서 날짜 글자만 눌러야 수정 → 행 전체 클릭 + '고치기' 버튼, 날짜 연도 표시
- 0~10 숫자 버튼이 좁은 화면에서 너무 작음 → 작은 화면에서 두 줄(0~5 / 6~10), 48px 이상
- 고치기 안내가 입력칸 아래에 있어 안 보임 → 입력칸 위로 이동, 문구를 쉽게
- 홈 위기 카드 '수정하기', 기록 '열어서 고치기'에서 돌아갈 길이 없음 → '돌아가기' 버튼
- 병원 사본 복원 시 무엇이 복원 안 되는지 안내, 저장 시각도 함께 전달
- 화면 전환 후 포커스 이동(키보드/보조기기), 설문 진행 수 고정 위치의 모바일 틈 보정, 위기 카드 줄바꿈, 설문 답하다 만 경우도 "이어서"로 표시

## 4회차 — 접근성·모바일·모션 전문가 관점 (고령 사용자, iPhone/Android, 태블릿)

- 하단 탭바 실제 높이(68~81px)가 고정 작업줄 계산값(64px)과 달라 '다음/저장' 버튼이 가려짐 → 탭바 높이를 변수로 통일
- 차트 축 글자가 폰에서 약 5px → 18px 상당으로 키우고 진한 색, 선 종류(실선/점선)로 흑백 인쇄·색각 이상 대응
- 강조색(#C2542F) 글자가 대비 4.5:1 미달 → 텍스트는 진한 강조색(#9F401F)으로, 밝은 강조색은 도형에만
- 입력칸·버튼 테두리 대비 1.6:1 → 3:1 이상 색으로. 잠긴 주차·준비 중 소리·비활성 버튼의 흐림 처리로 글자가 안 보이던 것 → 글자는 진하게 유지
- 터치 크기 48px 미만(글자 크기 버튼, 작은 버튼, 링크형 버튼, 표 안 링크, 상단 탭) → 모두 44~48px 이상
- 홈 화면 추가(standalone) 시 상단 노치 영역 겹침 → safe-area 반영
- 설문 라디오가 화면 밖(0×0)에 있어 보조기기 포커스가 튐 → 시각적으로만 숨김, 문항을 fieldset/legend로, 미응답 안내를 문항 안에 표시
- 일기 숫자 버튼에 radio 의미와 방향키 이동, 주차 아코디언을 제목>버튼 구조로, 표 머리글 scope, 화면마다 문서 제목 갱신, 장식 글리프 낭독 제외
- 포커스 표시가 없던 버튼·카드·탭에 뚜렷한 포커스 링. 스크롤 이동 시 고정 헤더에 가려지는 문제 → scroll-margin
- 읽어주기: 음성 목록이 늦게 채워지는 iOS/Android 대응, 긴 본문을 문장 단위로 나눠 끊김 방지, 실패 시 안내
- 악순환 고리 애니메이션이 무한 반복 → 3회. 주차 그림 그려지기 애니메이션은 세션당 1회. 모바일에서 숨기던 그림을 작게 표시
- 한글 단어 중간 줄바꿈(overflow-wrap:anywhere) → 본문은 정상 줄바꿈, 긴 사용자 입력만 강제 줄바꿈
- 인쇄: 탭바·고정 작업줄·읽어주기 버튼 제외, 표 잘림 방지, 색 유지
- 태블릿: 카메라 버튼이 영상 아래로 밀리던 것 → 위로, 스캔 중 화면 꺼짐 방지, 메모/붙여넣기 입력에 라벨

## 5회차 — 출시 준비 QA (QA 엔지니어 + 진료실 운영 관점)

**보안·안정성**
- 태블릿 페이지: 환자 데이터(날짜, 시점, 총점 등)를 이스케이프 없이 HTML에 넣어 조작된 QR/파일로 스크립트 실행 가능 → 모든 값 이스케이프, 전달 데이터 형식 검증(날짜 형식, 길이 제한, 시점 화이트리스트)
- 로드 시 상수 선언 순서 오류(TDZ)로 저장된 기록이 빈 상태로 대체될 수 있던 치명적 버그 발견·수정. 읽기 실패 시 원본을 백업 키로 보존
- 예전 형태·손상된 저장 데이터(키 누락, 답 없는 설문, 잘못된 날짜 키)를 정규화해 화면이 깨지지 않게 (jsdom 회귀 테스트 추가)
- 태블릿 저장 공간 부족 시 안내, 교체 취소 시 "저장했습니다"로 오인되던 흐름 수정
- 압축 해제를 지원하지 않는 오래된 iPad → 환자 폰의 '압축 없이' 옵션 안내
- 두 폰이 번갈아 카메라에 잡혀도 조각을 서로 지우지 않도록 조각을 세션별 보관

**날짜·시간**
- 소리 사용 기록을 UTC 날짜로 묶어 새벽 사용이 전날로 가던 문제 → 현지 날짜 기준. 병원 사본 복원 시각도 현지 기준, 점수 없는 날은 '실습만' 으로 복원
- 주간/야간 구분을 재생 시작 시각 기준으로(끝난 시각 기준이면 21:30 시작이 야간으로 잡힘)
- 시작일 형식 검증, 미래 날짜 확인

**설치·오프라인·프라이버시**
- 서비스 워커 추가(앱 껍데기만 캐시, 유튜브·폰트·의료진 페이지 제외), PNG 아이콘(iOS/Android 홈 화면), 환자 앱 푸터의 '의료진용' 링크 제거(태블릿은 주소 즐겨찾기)
- 태블릿: 마지막 백업 7일 경과·백업 없음 안내 배너(Safari 7일 저장소 정리 대비)

**진료실 기능 추가**
- 주간 이행도 표: 주차별 모듈 완료, 일기 일수, 사고기록 수, 마음챙김·근육이완 일수, 소리 주간/야간 — 숙제로 기대되는 항목은 진하게, 기록 없으면 붉게
- "지난 수신 이후" 카드: 새 일기·워크시트·모듈·소리 시간, 2주 평균 변화, 확인 필요 표시(THI 매우 심함, 수면 영향 8점 이상 5일+, 일기 7일 공백)
- 인쇄 시 스캔 UI 제외

**남긴 결정(사용자 판단 필요)**: 유튜브 대신 자체 오디오 호스팅(화면 꺼짐 중 재생, 외부 전송 없음), Google Fonts 제거, 차트 코드 공용화
