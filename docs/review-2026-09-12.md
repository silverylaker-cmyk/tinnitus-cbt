# 웹앱 검증 및 수정 — 2026-09-12

대상: `7bf4dcf`에서 분기한 수정안. 공개 사이트 접속 결과 HTTP 200.
환자 앱 33개 모듈·50개 화면, 의료진 파일 수신·상세 화면을 가상 데이터로 검사했다.
최근 커밋에서 의도적으로 제외한 1·8주차 THI 설문은 다시 추가하지 않았다.

## 발견 및 수정

| 문제 | 수정 |
| --- | --- |
| 누적 워크시트에서 한 칸만 수정하고 나갔다 오면 다른 칸이 비어 있음 | 수정 시작 시 전체 응답 보관, 기존 응답과 수정분 병합 |
| 마지막 기록을 삭제해도 버튼이 ‘다음으로’로 남음 | 삭제 후 버튼 상태 다시 계산 |
| 저장 공간 부족에도 ‘일기를 저장했습니다’ 표시와 화면 이동 | 저장 성공 여부를 확인하고 실패 시 입력 화면 유지. 가져오기·초기화 실패 시 기존 상태 복구 |
| 설문 응답을 선택한 순서에 따라 QR 복원 문항 순서가 달라짐 | q1~q25 순서로 전달. 기존 설문 수정 중 이전 응답 유지 |

| QR 압축 중 화면을 떠나면 늦은 응답이 타이머를 다시 만듦 | 떠난 화면 및 이전 요청의 결과 무시, 화면 켜짐 잠금 해제 |
| 서비스 워커가 같은 도메인의 다른 앱 캐시도 삭제 | 이 앱의 이전 버전 캐시만 정리, HTTP 오류 응답은 캐시하지 않음 |
| 의료진 ‘최근 2주’에 몇 달 전 기록까지 포함될 수 있음 | 내보낸 날을 포함한 실제 14일 구간으로 계산. 이전 사본도 각 내보낸 날짜 기준 |
| 새벽 워크시트의 주차가 UTC 날짜로 계산됨 | 의료진 기기의 현지 날짜로 계산 |
| 이름·입력값 일부가 HTML로 삽입될 수 있음 | 일기 점수, 설문 시점, 워크시트 버튼 속성 등 추가 이스케이프 |
| 처음 시작 안내가 길고 모바일 장식 여백이 큼 | 장식 축소, 기록 보존 안내 간결화, 큰 글자 화면 줄바꿈 개선 |
| 소리가 연결되지 않았는데 홈에서 재생 가능한 것처럼 보임 | 준비 상태를 홈에도 표시 |

공유 리소스와 환자·의료진 페이지, 서비스 워커 버전을 18로 맞췄다.

## 문구 검토

- ‘하루 10~15분이면 충분’은 개인 속도에 맞춰 시작하는 표현으로 수정.
- ‘이명 소리는 항상 똑같은 크기’라는 단정 제거.
- 안전행동을 줄여도 아무런 해가 없다는 단정을 제거하고, 큰 소음 환경에서의 귀 보호를 유지하도록 안내.
- CBT를 의료진 진료와 함께 사용하는 보조 도구라는 기존 안내 유지.

참고: [NIDCD 이명 안내](https://www.nidcd.nih.gov/health/tinnitus), [NIDCD 청력 보호](https://www.nidcd.nih.gov/health/hearing-protectors), [NICE NG155 권고](https://www.nice.org.uk/guidance/ng155/chapter/Recommendations).
이 검토는 프로그램 자체의 임상 효과를 입증하는 시험이 아니다.

## 검증 결과

- Chromium: 33개 모듈·50개 화면 탐색에서 JavaScript 오류 없음.
- 320 / 390 / 768 / 1280px, 글자 배율 100% / 130%에서 주요 7개 경로의 가로 넘침 없음.
- 홈·프로그램·일기·설정·워크시트의 axe WCAG A/AA 자동 검사 위반 없음. 수동 접근성 전체 인증을 의미하지 않음.
- 브라우저 회귀 6개, 통합 흐름 6개 통과: 일기 재접속, JSON 내보내기·가져오기, 의료진 수신, QR 화면 이탈, 오프라인 재접속, 실제 14일 구간 등.
- 56일 가상 일기·워크시트 7종·설문 2건·소리 56일을 압축 QR 4조각으로 만들고 픽셀에서 역순 해독, 원본 비교 통과.
- 서비스 워커 활성화 시 다른 앱 캐시 보존 테스트 통과.
- 원고 번들 재생성, JavaScript 문법 검사, diff 공백 검사 통과.

## 남은 운영 항목 / 검증 범위 밖

- `data/sounds.js`의 영상 ID 10개가 모두 비어 있다. 실제 소리 재생은 사용할 수 없으며 연결할 영상은 운영자가 선택해야 한다.
- 실제 iPhone/iPad의 카메라 QR 스캔, 음성 읽기, 홈 화면 설치, 장시간 백그라운드 재생은 기기에서 확인 필요. 이번 검사는 데스크톱 Chromium과 모바일 크기 에뮬레이션이다.
- 브라우저 저장 데이터의 모든 손상 형태, 대용량·악성 파일 전체 검증 및 보안 침투 테스트는 범위 밖이다.
- 미리 제작한 영상·음성은 재생성하지 않았다. 수정된 본문을 사용하는 앱의 ‘소리로 듣기’에는 새 문구가 적용된다.
- 운영 사이트 반영을 위한 main 병합·배포는 수행하지 않았다.

## 재실행

임시 의존성 폴더에 `playwright`, `@axe-core/playwright`를 설치하고 `NODE_PATH`로 지정한다.
기본 서버 주소는 `http://127.0.0.1:8765/`. 별도 터미널에서 저장소 루트의 정적 서버를 실행한다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

```sh
node tools/browser_regressions.cjs
node tools/browser_flows.cjs
node tools/browser_audit.cjs
node tools/service_worker_test.cjs
node tools/qr_roundtrip_test.js "$PWD"
python3 tools/build_content.py
```

브라우저 테스트는 별도 새 브라우저 컨텍스트에 가상 기록만 생성한다. `SITE`로 테스트 주소, `CHROMIUM_PATH`로 기존 Chromium 실행 파일, `ARTIFACT_DIR`로 스크린샷·가상 내보내기 파일의 저장 폴더를 지정할 수 있다. 기본 출력은 시스템 임시 폴더다.
설문 회귀 검사는 테스트 메모리에서만 모듈을 추가하여 이전 버전 데이터 호환성을 검증한다.
