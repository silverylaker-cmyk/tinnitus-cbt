나레이션 대본 편집기

어떻게 쓰나요 — 영상 1편 = 모듈 1개. 모듈은 여러 화면으로, 화면은 여러 큐(나레이션 한 문장 + 연출)로 이루어집니다. 큐 하나가 오디오 파일 하나입니다.
읽을 문장: 성우(TTS 또는 육성)가 읽는 말. 자막에도 이 문장이 나옵니다. 고치면 저장 뒤 node tools/tts.mjs 모듈이름 을 다시 돌려야 그 문장만 새로 녹음됩니다.
강조: 화면에 있는 문장 번호(0=제목). 그 문장이 살구색으로 표시되고 화면이 그쪽으로 스크롤됩니다. 아래 "화면 문장" 목록의 번호를 고르세요. 없음 = 강조 안 함.
가리키기: 손가락 포인터가 갈 요소. 자주 쓰는 것은 목록에서 고르고, 그 밖에는 CSS 선택자를 직접 적습니다. 누름을 켜면 누르는 동작과 파문이 나옵니다.
타이핑: 입력칸(필드 키)에 글자를 한 자씩 치는 시연. 문장은 타이핑할 내용입니다.
순서·추가·삭제: ▲▼ 로 순서를 바꾸고, "+ 큐" 로 문장을 끼워 넣습니다. 임상 문장(교육 내용)은 여기서 고치지 말고 content/*.json 에서 고친 뒤 node tools/make_scripts.mjs --force --only=모듈 로 다시 뽑으세요(이 파일은 .bak 으로 남습니다).
저장 후 미리보기: npm run studio · 최종 출력: npx remotion render 모듈-이름 out/모듈.mp4
